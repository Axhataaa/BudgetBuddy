# Development Roadmap

## Project Title

BudgetBuddy – Personal Budget Planning and Expense Management Platform

---

## Objective

The objective of BudgetBuddy is to provide users with a simple and secure platform to manage their personal finances.

Users can record income, track expenses, create budgets, monitor savings goals, receive notifications, and generate financial reports.

---

## User Role

### Registered User

The user can:

- Register and Login
- Manage Profile
- Track Income
- Record Expenses
- Create Budgets
- Set Savings Goals
- View Reports
- Receive Notifications

---

## Technology Stack

### Backend

- Django
- Django REST Framework

### Frontend

- React + Vite

### Database

- SQLite (Development)
- PostgreSQL (Future)

---

## Development Approach

The application follows a REST API architecture where the frontend communicates with the backend through secure API endpoints protected using JWT Authentication.
